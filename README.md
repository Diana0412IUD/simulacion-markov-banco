# Simulación de un Sistema de Atención Bancaria

Proyecto desarrollado para la asignatura de Simulación.

## Tecnologías utilizadas
- Java
- Modelos de Markov
- Distribución de Poisson
- Distribución Uniforme

## Descripción
Este proyecto simula el comportamiento de un sistema de atención bancaria con una sola caja, ejecutando 10.000 simulaciones para analizar indicadores estadísticos.

- SimulacionBanco.java
- Informe del proyecto
- Gráficas y capturas
